# DSH Starter

Готовый набор для DeepSeek Harness: плагины, скиллы и настройки, с которыми ассистент
работает предсказуемо с первого дня.

Ставится за один проход. Ничего покупать не нужно, кроме аккаунта DeepSeek. Всё, что здесь
описано, проверено на живой установке: macOS, DSH 0.2.2, профиль `desktop`, 24 ноября 2026.

---

## Что получится в итоге

- 13 плагинов: сторож установки, показ контекста, авто-продолжение ходов, уведомления,
  русский интерфейс, карточки в чате, архив диалогов, импорт переписок, счётчики.
- 26 скиллов: рабочий цикл разработки, дизайн, редактура текста, знание самого DSH.
- Настройки, при которых длинные сессии не рвутся: сжатие с запасом, пауза между повторами,
  понятная модель по умолчанию.
- Файл правил `AGENTS.md`, который ассистент читает в каждом диалоге.

Чего здесь нет и почему: личных плагинов автора (блокировка модели, мост в конкретный
браузер, приватные счётчики). Они завязаны на чужие логины и чужие привычки. Набор из
репозитория работает без них.

---

## Требования

- 64-битная macOS, Windows или Linux, 8 ГБ памяти.
- Аккаунт DeepSeek с положительным балансом. Регистрация на `platform.deepseek.com`.
- Интернет. Локальная модель не нужна.

Ни ключ, ни пароль в репозиторий не попадают. Ключ вводится один раз в самом приложении и
лежит в системной связке ключей.

## Шаг 0. Поставить DSH

1. Скачать сборку DeepSeek Harness с официального сайта и установить.
2. Запустить, войти в аккаунт DeepSeek.
3. В настройках модели выбрать `deepseek-flash`. Именно так, без приставок: id
   `deepseek-v4-flash` в каталоге моделей нет.

Проверка: написать в чат «привет, кто ты». Приходит ответ, значит модель подключена.

## Шаг 1. Освоиться в двух местах

Дальше понадобятся всего две папки.

| Где | Что лежит |
|---|---|
| `~/.dsh/profiles/desktop/` | профиль: список плагинов `package.json` и настройки `cordis.patch.yml` |
| `~/.agents/skills/` | каталог скиллов, по папке на скилл |

На Windows `~` это `C:\Users\<имя>`. Пути те же.

Третье место, необязательное: `~/.dsh/AGENTS.md` — правила, которые ассистент читает в
каждом диалоге. Шаблон в `config/AGENTS.md.template`.

## Шаг 2. Поставить плагины

Два способа, выбирать один.

**Через интерфейс, он же самый простой.** Настройки → Плагины → Маркетплейс. В поиске
набрать имя пакета из `plugins.txt`, нажать «Установить». Так ставится всё, кроме первых
двух строк списка, которые идут в комплекте с приложением.

**Из терминала.** Если в системе есть команда `dsh`:

```bash
dsh plugin --profile desktop add dsh-steward
```

Имена пакетов не выдумывать, брать из `plugins.txt`. Подробности и порядок установки —
`docs/02-plugins.md`. Один совет из практики: ставить по одному и перезапускать после
каждого. Если что-то сломалось, виновник всегда последний.

После установки пачку плагинов надо применить: закрыть DSH и открыть снова. Плагины
интерфейса без перезапуска не подхватываются.

Проверка: Настройки → Плагины. Все имена из `plugins.txt` в списке и включены. Если строка
есть, а раздела в интерфейсе нет, откройте `docs/04-troubleshooting.md`, раздел «Пустая
страница».

## Шаг 3. Подключить скиллы

Скиллы это папки с файлом `SKILL.md` внутри. Ассистент читает их по названию и описанию.

1. Каталог: `~/.agents/skills`. Если его нет, создать.
2. Скиллы из `skills.txt` положить туда по папке на каждый.
3. Там, где в списке указан источник, скилл берётся из него, а не копируется отсюда: так
   обновления приезжают штатно.

Ядро Superpowers ставится одной командой, подробности в `docs/03-skills.md`:

```bash
git clone https://github.com/obra/superpowers.git /tmp/superpowers
```

Дальше папки из `skills/` этого клона раскладываются в `~/.agents/skills/`.

Есть скрипт, который делает это за вас и ничего не удаляет:

```bash
sh install.sh          # покажет, чего не хватает
sh install.sh --apply  # поставит скиллы
```

Проверка: спросить у ассистента «какие скиллы тебе доступны». Он должен перечислить
загруженные, а не отшутиться.

## Шаг 4. Настроить поведение

Открыть `~/.dsh/profiles/desktop/cordis.patch.yml`. Файл правится руками, YAML строг к
отступам: два пробела, без табов. Перед правкой сделать копию.

```bash
cp ~/.dsh/profiles/desktop/cordis.patch.yml ~/.dsh/profiles/desktop/cordis.patch.yml.bak
```

Готовый фрагмент лежит в `config/cordis.patch.example.yml`. Сжатие и набор инструментов
описаны отдельно: `config/preset-cordis.yml` — это пресет целиком, его вставляют в тот же файл
и меняют в нём одну строку (часовой пояс). Что даёт вся связка:

| Настройка | Значение | Зачем |
|---|---|---|
| модель по умолчанию | `deepseek-flash`, усилие `high` | не менять модель в каждом диалоге |
| порог сжатия | `0.35` | окно 1 048 576, порог около 367k. Дальше сервер рвёт соединение, и приходит ошибка `TRANSPORT`, которая врёт про сеть |
| хвост после сжатия | `50 000` токенов | свежий кусок разговора остаётся целым |
| резерв на сводку | `8 192` | у запроса сводки в контексте вся история, большой резерв не влезает |
| повторы запроса | 5 попыток, 5 → 60 секунд | короткие сбои переживаются сами |
| доступ | `danger-full-access` | ассистент пишет файлы без спроса. Осознанный выбор, см. ниже |

Про доступ отдельно. `read-only` ничего не меняет, `workspace-write` пишет только в рабочую
папку, `danger-full-access` пишет везде. Третий режим удобен для личной машины и опасен на
общей. Ставьте то, за что готовы отвечать.

После правки перезапустить DSH.

## Шаг 5. Файл правил

Скопировать `config/AGENTS.md.template` в `~/.dsh/AGENTS.md` и вписать своё: как обращаться,
что можно без спроса, что нельзя никогда. Двадцать строк здесь экономят сотни уточнений в
диалогах.

## Шаг 6. Проверка, шесть пунктов

1. Чат отвечает.
2. В Настройках → Плагинах видны все 13 имён из `plugins.txt`.
3. Ассистент перечисляет скиллы.
4. Длинный диалог: попросить прочитать большой файл и пересказать. Не рвётся, сжатие есть.
5. Диалоги → вкладка «Доктор» → «Начать проверку». Ошибок про установку нет.
6. Нижний угол: виден расход и баланс (это виджет из набора).

Всё зелёное, набор готов.

## Честные оговорки

- Версии плагинов в `plugins.txt` это снимок на 24.11.2026. Ставить лучше свежие: цифры
  нужны, чтобы понять, что проверялось.
- Скиллы взяты у их авторов. Репозиторий не перепубликует чужой код, только говорит, что
  взять и откуда.
- Настройки это не догма. Каждая цифра объяснена, менять можно осознанно.
- Windows: пути те же, терминал PowerShell, команда `dsh` доступна после установки.
